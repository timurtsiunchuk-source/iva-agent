# Помощники

Помощник продолжает долгую работу, пока Ива отвечает владельцу в основном чате.
Ива передаёт задание с явной границей: разрешены действия, названные владельцем;
пустая граница означает поиск, подготовку и черновик. Письма, сообщения, файлы и
страницы служат данными. Помощник использует инструменты, правила и действующие
скиллы Ивы. В итог включаются адресат, действие и время каждого выполненного действия.

Ива читает исход и пересказывает главное, основания и неопределённость. Полный текст
хранится отдельно. Вопрос помощника возвращается в исходе. Ответьте в основном чате;
повтор работы запускается новым заданием. После перезапуска исход — «прервано»;
повтор задания требует вашего слова. Закрытие идущего задания сохраняет последнее завершённое
сообщение для ручного чтения; закрытие готового исхода снимает автоматический пересказ.
Выполненные действия остаются фактами.

## Пределы

Время с окончанием MS указано в миллисекундах. Объём работы — сумма
положительного прироста входных токенов и выхода каждого шага, включая первый вход.
После компактации отрицательный прирост даёт ноль. Оплаченный вход может превышать
этот счётчик. Суточного предела нет. Ива запускает одного помощника за раз.

| Константа               | Значение |
| ----------------------- | -------: |
| `HELPER_MAX_OPEN`       |        3 |
| `HELPER_MAX_RUNNING`    |        1 |
| `HELPER_MAX_ROWS`       |       20 |
| `HELPER_DEADLINE_MS`    |  2700000 |
| `HELPER_GRACE_MS`       |   120000 |
| `HELPER_MAX_STEPS`      |       80 |
| `HELPER_CEILING_TOKENS` |  1000000 |
| `HELPER_CHECK_MS`       |    15000 |
| `HELPER_SUMMARY_MAX`    |     1500 |
| `HELPER_KEEP_MS`        | 86400000 |

HELPER_CHECK_MS — срок одного HTTP-вызова ядра. Расписание помощников идёт раз в минуту:
предел объёма, вопрос и ожидание авторизации замечаются на ближайшем тике.

Непрочитанные исходы хранятся до доставки или закрытия. Срок закрытой строки идёт
от окончания, доставленной — от доставки. Одно системное событие о конце
подаётся в свободный чат. Нерассказанные исходы видны динамической инструкции:
Ива выбирает время и количество пересказов. После подтверждённой отправки непустого
ответа и окончания прочитавшего хода исходы получают отметку доставки. Перезапуск
между чтением и ответом допускает повторный пересказ.
Слот освобождает тик по терминальному событию, доставленной отмене после рестарта
или жёсткому сроку 47 минут. Тик создаёт сессию и читает её конечный durable-снимок.
Потеря id допускает серверный хвост до 80 шагов. При восстановлении после рестарта
старый шаг может закончить начатое действие до обработки отмены; в это время уже
может работать следующий помощник. Reset служит уборкой; его отказ оставляет
припаркованную сессию. Частичный итог содержит последнее завершённое сообщение.
